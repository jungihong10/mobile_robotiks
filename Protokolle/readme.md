# Protokolle

In dieses Verzeichniss bitte alle Abgaben speichern und die ``.pdf`` files __einchecken__!
<br>
Bitte das ``.pdf`` zum aktuellen Blatt rechtzeitig auch auf ILIAS __hochladen__!

Für jedes Protokoll das Template ``protocol_template.tex`` in ein neues File ``protocol_xx.tex`` kopieren und dort bearbeiten.
<br>
Auf jedes Protokoll muss
 
* Namen der Gruppenmitglieder
* Gruppennummer
* Blattnummer
